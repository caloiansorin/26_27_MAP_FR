# \# Ghid de utilizare Git și GitHub

# 

# Acest document descrie pașii principali pentru lucrul pe un branch dedicat și salvarea modificărilor pe GitHub.

# 

# \## 1. Clonarea proiectului local

# git clone https://github.com/caloiansorin/26\_27\_MAP\_FR

# cd 26\_27\_MAP\_FR

# 

# \## 2. Crearea și comutarea pe un branch nou

# git switch Tilea-Alexandru

# 

# \## 3. Salvarea modificărilor locale

# git add README.md

# git commit -m "Adaugat README.md"

# 

# \## 4. Trimiterea modificărilor pe GitHub

# git push -u origin Tilea-Alexandru
