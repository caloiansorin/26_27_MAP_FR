# Ghid pasi Git - Andrei Lavinia

1. Clonarea proiectului:
git clone https://github.com/caloiansorin/26_27_MAP_FR

2. Accesarea folderului:
cd 26_27_MAP_FR

3. Actualizarea informatiilor:
git fetch origin

4. Crearea si comutarea pe branch:
git checkout -b Andrei-Lavinia

5. Crearea fisierului de test:
touch test.txt

6. Salvarea modificarilor:
git add .
git commit -m "Rezolvare laborator"

7. Trimiterea pe GitHub:
git push origin Andrei-Lavinia
