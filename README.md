# Ghid Rapid - Ce este și cum se folosește GitHub?

**GitHub** este o platformă web bazată pe sistemul Git, folosită pentru stocarea codului și colaborarea în echipă.

## Concepte de bază:
* Repository (Repo): Spațiul în care este stocat întregul proiect.
* Branch (Ramură): O copie de lucru separată pentru a dezvolta funcționalități fără a afecta codul principal (`main`).
* Commit: O salvare oficială a modificărilor făcute în cod, însoțită de un mesaj descriptiv.
* Pull Request : O cerere de a integra modificările de pe un branch în branch-ul principal.

## Fluxul de lucru și comenzi utile:
1. Creare branch nou: "git checkout -b nume-branch"
2. Adăugare fișiere modificate: "git add ."
3. Salvare locală (Commit):"git commit -m "Mesaj ."
4. Trimitere pe GitHub (Push): "git push origin nume-branch"
