### Instalare
Pasii necesari pentru a putea instala aplicatia noastra

1. Clone the repository:
   ```bash
   git clone https://github.com/adinanistor/proiect.git
   ```
2. Navigate into the project directory:
   ```bash

   ```
3. Install dependencies:
